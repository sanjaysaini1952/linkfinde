# MASTER PROMPT — BUILD A PREMIUM WEBSITE DIRECTORY PLATFORM

You are a senior UI/UX designer, product designer, and full-stack Next.js engineer.

Build a complete, production-ready website directory platform inspired by the concept of curated internet directories such as FMHY, but DO NOT copy its design, branding, layout, text, or visual identity.

The platform's purpose is simple:

> Create one trusted place where users can discover useful websites and easily access their actual/official website links.

The website should feel like a premium combination of:

* Internet directory
* Search engine
* Resource library
* Website discovery platform
* Curated knowledge base

The design must be modern, futuristic, clean, highly usable, fast, responsive, and visually impressive.

---

# 1. CORE PRODUCT IDEA

Users should be able to:

1. Search for websites.
2. Browse websites by category.
3. Browse websites by tags.
4. Open a website's official link.
5. Copy a website URL.
6. Discover trending websites.
7. Discover recently added websites.
8. See whether a website is verified.
9. Submit a website.
10. Report a broken or incorrect link.
11. Bookmark/favorite websites.
12. Share website pages.
13. Filter results.
14. Sort results.
15. Explore curated collections.

The platform administrator should be able to:

* Add websites
* Edit websites
* Delete websites
* Verify websites
* Feature websites
* Manage categories
* Manage tags
* Review submissions
* Manage reports
* Monitor broken links
* View analytics
* Manage users
